# a_fun_game — локальный каталог настольных игр

## Запуск для показа
Дважды нажмите START_SITE.cmd или выполните:
```powershell
python -B app.py --open
```
Адрес: http://127.0.0.1:8000 . Окно сервера оставьте открытым; Ctrl+C завершает работу.
Если сервер уже запущен, просто откройте этот адрес.

## Возможности
Поиск по названию и теме, 12 взвешенных критериев: состав компании, время партии,
объяснение правил, сложность правил, сложность игры, жанр, формат, впечатление, механика, наличие,
избранное и поисковый запрос. Семь сценариев вечера заполняют видимые поля.

Игры ранжируются по сумме баллов; веса можно менять в «Что для вас важнее?».
Сначала показываются шесть лучших вариантов, остальные — по кнопке.
В карточках есть процент соответствия, а в подробностях — расчёт каждого вклада.

Единственное жёсткое исключение — участников больше известного максимума игры.
Нехватка игроков, превышение желаемого времени и другие несовпадения снижают балл,
но не скрывают игру. Неизвестные значения обозначаются явно и не считаются совпадением.
Наличие, избранное и поиск тоже повышают приоритет, сохраняя остальные альтернативы.
Без пожеланий доступна обычная коллекция из 72 игр с локальными обложками.

Избранное хранится в браузере. «Помочь выбрать» при наличии пожеланий выбирает
из трёх лидеров. Добавление игр в MySQL работает в локальном режиме с базой.

Формула, веса и источники характеристик: [RECOMMENDATIONS.md](RECOMMENDATIONS.md).
Для загрузки обложек после пополнения: `python -B fetch_images.py`.

## Данные
Жанры загружаются через game_genres / genres, механики — через game_mechanics / mechanics.
Впечатления и уровень кооперации берутся из impression и level_of_cooperation.
Сложность правил rules_difficulty (1–5), сложность игры complexity_of_game (1–9)
и время объяснения time_for_rules_min являются тремя отдельными критериями.
В текущей базе 12 из 72 игр не имеют жанров, механик и сложности правил;
это явно обозначается и не исключает их из подбора.

Исходная таблица mda_board.games содержала 60 игр. seed_catalogue.py добавляет 12 записей
со ссылками на страницы издателя Gamewright; повторный запуск пропускает существующие названия.
Перед вставкой создаётся JSON-копия всех записей и CREATE TABLE в backups/.
Существующие записи не перезаписываются. Наличие новых игр оставлено NULL (неизвестно).
Сложность новых игр — редакционная оценка, а не рейтинг издателя.
Данные издателя о количестве игроков и длительности относятся к указанным изданиям.
Источники доступны в карточке каждой новой игры.

Если MySQL недоступна, сайт показывает data/catalogue.json с явной отметкой о резервной копии.
В этом режиме добавление отключено. Копия обновляется командой python -B export_catalogue.py (только чтение MySQL);
обычные добавления через форму не обновляют её автоматически.

## Подключение
Сервер читает только литералы настроек подключения из существующего note-book.py, не запускает его.
Можно переопределить MYSQL_HOST, MYSQL_USER, MYSQL_PASSWORD, MYSQL_DATABASE переменными окружения.
Старое .venv перенесено с другого компьютера и не запускается, поэтому используется системный Python.
Модуль mysql.connector читается из .venv/Lib/site-packages. Для чистой установки:
```powershell
python -m pip install -r requirements.txt
```
Сервер доступен только на этом ноутбуке и предназначен для локальной демонстрации.

## Сценарий демонстрации на 2–3 минуты
1. Откройте каталог и выберите «На одной стороне» или «Вечер на двоих».
2. Измените число участников, жанр и время: лучшие варианты обновятся сразу.
3. Откройте лидера: процент, баллы критериев, совпадения и оговорки.
4. Раскройте «Что для вас важнее?» и измените вес жанра или формата.
5. Добавьте игру в избранное и включите «Предпочитать мои избранные».
6. Нажмите «Ещё варианты», затем «Помочь выбрать».
7. Для добавления в MySQL используйте локальную форму при доступной базе.

## Проверки
`python -B -m unittest test_app.py` — проверки сервера.
`python -B qa_recommendations.py` или `python -B qa_browser.py` — проверка
взвешенного подбора и адаптивного интерфейса в Chrome. Нужны Playwright
(поддерживается установка в .tools) и Chrome. Используется сохранённый каталог;
MySQL не изменяется. Скриншоты сохраняются в artifacts/.
