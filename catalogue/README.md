# a_fun_game — локальный каталог настольных игр

## Запуск для показа
Дважды нажмите START_SITE.cmd или выполните:
```powershell
python -B app.py --open
```
Адрес: http://127.0.0.1:8000 . Окно сервера оставьте открытым; Ctrl+C завершает работу.
Если сервер уже запущен, просто откройте этот адрес.

## Возможности
Поиск по названию и описанию, фильтры по игрокам/времени партии/времени на правила/наличию, подбор по близости сложности,
быстрые сценарии, избранное в браузере, случайная игра, подробная карточка и добавление в MySQL.
Сложность влияет на порядок рекомендаций, а не исключает игры. Игроки и время — строгие ограничения.
Быстрый сценарий «Лёгкий старт» исключает игры сложнее 3.
Для доступных игр используются локальные изображения коробок; остальные показывают декоративную заглушку. Источники изображений сохранены в data/images.json и доступны в карточках. Фильтр времени на правила использует time_for_rules_min; неизвестные значения исключаются при включённом ограничении.
Все 72 игры текущего каталога имеют локальные обложки. Издания и язык коробок могут отличаться от экземпляров клуба.
Для загрузки обложек после пополнения каталога: `python -B fetch_images.py` (нужен интернет; существующие файлы не скачиваются повторно).
Время объяснения правил доступно в карточках и в форме добавления игры. Пустое поле означает «неизвестно».

## Данные
Исходная таблица mda_board.games содержала 60 игр. seed_catalogue.py добавляет 12 записей
со ссылками на страницы издателя Gamewright; повторный запуск пропускает существующие названия.
Перед вставкой создаётся JSON-копия всех записей и CREATE TABLE в backups/.
Существующие записи не перезаписываются. Наличие новых игр оставлено NULL (неизвестно).
Сложность новых игр — редакционная оценка, а не рейтинг издателя.
Данные издателя о количестве игроков и длительности относятся к указанным изданиям.
Источники доступны в карточке каждой новой игры.

Если MySQL недоступна, сайт показывает data/catalogue.json с явной отметкой о резервной копии.
В этом режиме добавление отключено. Копия обновляется командой python seed_catalogue.py;
обычные добавления через форму не обновляют её автоматически.

## Подключение
Сервер читает только литералы настроек подключения из существующего note-book.py, не запускает его.
Можно переопределить MYSQL_HOST, MYSQL_USER, MYSQL_PASSWORD, MYSQL_DATABASE переменными окружения.
Старое .venv перенесено с другого компьютера и не запускается, поэтому используется системный Python.
Модуль mysql.connector читается из .venv/Lib/site-packages. Для чистой установки:
```powershell
python -m pip install -r requirements.txt
```
Сервер доступен только на этом ноутбуке и предназначен для локальной демонстрации.

## Сценарий демонстрации на 2–3 минуты
1. Покажите каталог и число игр.
2. Нажмите «До 30 минут», выберите 4 игроков, объяснение правил до 5 минут и сложность 3.
3. Откройте карточку: описание, длительность, правила и источники.
4. Добавьте игру в избранное и включите «Мои избранные».
5. Сбросьте фильтры и покажите поиск по слову «остров».
6. Откройте форму «Добавить игру»: она сохраняет запись непосредственно в MySQL.
7. Нажмите «Случайная игра», чтобы выбрать игру для вечера.
